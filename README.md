# Business Sales Performance Analysis & Decision Dashboard

## Project Overview

This project focuses on analyzing sales data and transforming it into actionable business insights using Microsoft Excel and Power BI.

## Objectives

* Clean and prepare raw sales data
* Analyze sales performance across regions and products
* Identify key business KPIs
* Create an interactive Power BI dashboard
* Generate business recommendations

## Tools Used

* Microsoft Excel
* Power BI Desktop

## Key Metrics

* Total Revenue
* Total Profit
* Profit Margin
* Top Performing Products
* Best Performing Region
* Monthly Sales Trends

## Dashboard Features

* KPI Cards
* Product Performance Analysis
* Region-wise Sales Distribution
* Monthly Sales Trend Analysis
* Interactive Slicers

## Business Insights

* Identified top-performing products and regions
* Analyzed monthly sales patterns
* Evaluated profitability trends
* Generated data-driven recommendations
